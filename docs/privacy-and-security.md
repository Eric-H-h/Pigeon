# 隐私与安全说明

## 数据流

OTPigeon 处理的数据只有快捷指令传来的 JSON：配对令牌与短信正文。Windows 在内存中验证令牌、提取验证码，然后把验证码写入剪贴板。程序不会把请求正文、令牌或验证码写入日志、配置文件或分析服务。

配置文件只保存随机安装 ID、随机配对令牌和端口，位置是：

```text
%LOCALAPPDATA%\OTPigeon\config.json
```

该文件属于敏感数据，不应提交到 Git、上传网盘或公开截图。

## 为什么必须使用受信任的专用网络

OTPigeon V0.2 使用局域网 HTTP，不提供端到端加密：

- Windows 自己创建的热点通常只有 Windows 与你的 iPhone，攻击面较小；
- 自己管理的路由器可以使用，但两台设备必须连接普通 LAN，不能进入访客网络；
- 不应让两台设备直接连接酒店、校园或公司公共 Wi-Fi；
- 在校园网络后使用自己的路由器时，OTPigeon 流量应只在路由器内部 LAN 中传输，不要配置公网端口转发。

Windows 当前连接应设置为“专用网络”，OTPigeon 防火墙也只允许“专用”。“公用网络”代表设备处于不受信任环境，不应为了绕过错误的防火墙规则而长期切换到公用。

## 配对令牌

首次启动会生成至少 128 位随机强度的令牌。收到请求时，服务端使用常量时间比较。令牌泄露或电脑转交他人时，在窗口中选择 **Regenerate token**，然后更新 iPhone 快捷指令。

令牌不是账号密码：它只保护当前电脑的本地 OTPigeon 端点，但仍应按敏感信息处理。

## 剪贴板

OTPigeon 写入验证码时，使用 Windows 提供的剪贴板格式标记，请求：

- 排除剪贴板历史；
- 禁止上传云剪贴板；
- 排除剪贴板监视处理。

这些标记由 Windows 和相关应用决定是否遵守，不能作为绝对安全保证。验证码仍会短暂存在于普通剪贴板中，任何能读取当前剪贴板的本机应用都可能访问它。

## 防火墙建议

首次运行 EXE 时，Windows 可能询问网络访问权限：

- 只允许 **专用网络**；
- 不允许 **公用网络**；
- 不要在路由器上把 TCP 8765 映射到公网。

程序还会在应用层拒绝非回环、非 RFC1918 来源；防火墙仍是第一道边界，不能因此省略。
