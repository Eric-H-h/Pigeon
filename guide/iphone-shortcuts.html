Setup guide

把验证码短信送到
Windows 剪贴板

这页只讲 iPhone。Windows 程序窗口还在制作，你只要让电脑上的服务处于运行状态，并拿到它显示的地址和配对 Token。插图按 iOS 18.4.1、英文 Shortcuts 绘制，并对照了真机截图；需要看中文系统界面时，点右上角切换。

橙色描边表示这一步要点的位置

  • 1. 网页发码你自己点「发送验证码」
  • 2. iPhone 收短信锁屏也可以
  • 3. Shortcuts 转发局域网 HTTP POST
  • 4. Windows 提取只在电脑内存里处理
  • 5. Ctrl+V验证码已在剪贴板
隐私边界 运行时短信和验证码不经过云端、也不经过大模型。Apple 分享 Shortcut 文件时会走它自己的验证机制，那是 Shortcut 定义，不是你的短信内容。

你要配两样东西

不要把整条 HTTP 逻辑只写在个人自动化里。个人自动化没法作为主要分享单元；普通 Shortcut 可以。

这块名称作用能不能分享
普通 Shortcut Send to OTPigeon 把短信正文 POST 到电脑的 /otp 可以。别人导入时填自己的地址和 Token。
Personal Automation Message 触发 短信包含「验证码」时立刻运行上面的 Shortcut 不能当主分享物。每个人在自己手机上建一次。

开始前

  • iPhone 系统为 iOS 18.4.1 或同代 Shortcuts。本页按 18.4.1 英文界面。
  • iPhone 已连上 Windows 热点，或同一台可信的家庭路由器。不要依赖酒店、校园、公司访客 Wi-Fi。
  • Windows 上 OTPigeon / OTP Bridge 已经在运行。
  • 准备两样从电脑复制的值：PC Address 和 Pairing Token。
验证码 Send to OTPigeon token text /otp
STEP 0

先用 Safari 确认手机能访问电脑

还不要做 Shortcut。在 iPhone Safari 地址栏打开：

http://你的PC地址:8765/health

页面出现 OK 字样就可以往下走。这一步能排除「根本没连上」：热点、防火墙、地址填错，都会在这里暴露。

还没 OK？先别配 Shortcuts 确认 iPhone 与电脑在同一可信局域网，Windows 当前连接和 OTPigeon 防火墙权限都使用专用网络，并且地址没有写成 127.0.0.1。如果只有切成公用网络才成功，说明防火墙权限勾反了。

第一部分：创建普通 Shortcut

先做出 Send to OTPigeon。以后 Message 自动化只负责「在收到短信时运行它」。iPhone 不解析验证码，解析留在 Windows。

STEP 1

打开 Shortcuts，新建一条

  1. 打开 Shortcuts 应用。
  2. 确认底部选中左边的 Shortcuts 标签，不是 Automation。
  3. 点右上角 +。
STEP 2

改名，并加入三个动作

点顶部名称，改成 Send to OTPigeon。底部搜索栏依次加入：

  1. Text：内容选变量 Shortcut Input。不要手打短信。
  2. URL：填电脑地址，并以 /otp 结尾。
  3. Get Contents of URL：下一步再展开改 POST。

URL 的最终形态必须是下面这样，不要重复粘贴 http://，也不要漏掉 /otp：

http://PC_ADDRESS:8765/otp

为什么要先放一个 Text？ 短信原文先变成 Text 动作的输出，下一步 JSON 的 text 字段才能稳定引用它。不要在 iPhone 上提取验证码。
STEP 3

把 Get Contents of URL 改成 POST JSON

这是最容易漏的一步。点该动作右侧的 ›，或点 Show More。

  1. Method 改成 POST。默认 GET 发不出短信。
  2. Headers 不用改。
  3. Request Body 选 JSON。
  4. 添加两个字段，键名必须是英文小写：
Key类型Value
tokenTextWindows 上的 Pairing Token，原样粘贴
textText点变量，选上一步 Text 的输出，不要手打
键名不要翻译 写成「令牌」或「短信」都会失败。Windows 只认 token 和 text。

第二部分：创建 Message 个人自动化

普通 Shortcut 不会自己跑。要让锁屏状态下的验证码短信触发它，必须再做一次 Personal Automation。

STEP 4

到 Automation 标签，点 +

底部中间是 Automation。如果这是你的第一条自动化，界面可能先出现 Create Personal Automation，点它即可。已经有自动化时，点右上角 +。

STEP 5

触发器选 Message

在列表里找到 Message。不要选 Email，也不要选 App。验证码来自短信，不是来自某个 App 的通知。

插图把其余项目降低对比度，这是教程简化，真机上列表会更长。

STEP 6

包含「验证码」，并且立即运行

这一屏必须和真机一致，三项都不要改错：

  1. Sender 保持 Choose，不要选联系人。验证码号码每次都可能不同。
  2. Message Contains 填 验证码。多数国内短信用这三个字；只写 code 会漏掉中文短信。
  3. 必须勾 Run Immediately。如果留在 Run After Confirmation，锁屏时还要你点确认，这条链路就没有意义。

然后点右上角 Next 或 Done。

STEP 7

运行已有的 Send to OTPigeon

iOS 18 在触发条件之后会让你选：新建空白自动化，或使用已有 Shortcut。选 Send to OTPigeon。

不要选 New Blank Automation 把 Text / URL / Get Contents of URL 直接写进自动化也能跑通，但那份自动化没法作为主要分享物。分享给别人时，应让他们导入普通 Shortcut，再自己选一次「运行该 Shortcut」。
STEP 8

核对 When / Do

完成后点进这条自动化，应看到：

  • When：When I Get a Message Containing '验证码'
  • Do：运行 Send to OTPigeon
  • 顶部运行方式是 Run Immediately

点进 Do，确认传入的是短信本身，也就是 Shortcut Input。不要改成剪贴板或空输入。

如果我已经把三个动作写在自动化里了？

那就是当前已经跑通的个人 PoC：Do 会显示 Text, URL, and Get Contents of URL。自己用可以不改。要分享给别人时，请把这三个动作搬进普通 Shortcut，自动化只保留「运行该 Shortcut」。

第三部分：第一次运行

STEP 9

允许 Shortcuts 访问电脑

第一次真正发出 HTTP 请求时，iOS 通常会询问是否允许这条 Shortcut 访问该地址。必须选 Allow。选错一次，后面锁屏转发会静默失败。

建议先在解锁状态下用一条含「验证码」的短信触发，或点 Shortcut 编辑器里的播放按钮发一次（播放按钮没有短信正文时，Windows 可能返回未识别，但权限弹窗仍会出现）。

Local Network 设置里可能看不到 Shortcuts 真机已经验证：设置里即使不出现 Shortcuts，HTTP 仍然可以成功。不要把「设置里找不到 Shortcuts」当成失败依据。
STEP 10

锁屏再收一条真实验证码

列表里应出现一条个人自动化，标题含 验证码。然后按实际使用来验收：

  1. Windows 服务保持运行。
  2. 把 iPhone 锁上。
  3. 在电脑网页点「发送验证码」。
  4. 短信到达后，不要解锁手机，直接在 Windows Ctrl+V。

成功时，电脑上只会看到掩码状态，例如 6****1，完整验证码只进剪贴板。

地址以后会变怎么办

这是别人用起来最常见的痛点。Shortcut 里保存的是你填进去的数字地址。Windows 热点关闭再开、换了网卡或路由器重新分配地址后，IP 可能变化。

你现在填的是IP 变了以后
窗口当前显示的数字地址，例如 192.168.5.101 复制窗口里的新地址，打开 Send to OTPigeon，只改 URL 动作中的 IP。自动化不用重建。
改地址只改普通 Shortcut 这就是拆成两块的好处：个人自动化仍然监听「验证码」，只有 URL 那一处要更新。OTPigeon 不再使用 .local 名称。

常见问题

锁屏没有反应

先确认运行方式是 Run Immediately，而不是 Run After Confirmation。再确认自动化仍处于启用状态。最后用 Safari 再打开一次 /health，排除网络。

Windows 提示 Token 错误

JSON 的 token 必须和电脑上当前 Token 完全一致。重新生成 Token 后，旧 Shortcut 会立刻失效，需要再贴一次。

电脑收到请求但没有验证码

说明 HTTP 已经通了，是提取规则没有找到唯一的 4–8 位数字。把短信里「验证码」附近的数字格式记下来。iPhone 端不要自己截取数字。

同一 Wi-Fi 却互相访问不了

公共网络常开 AP / Client Isolation。改用 Windows 移动热点，不要继续调路由器。

以后导入别人分享的 Shortcut 文件

导入时会问 PC Address 和 Pairing Token，不会带上作者的地址。系统可能要求打开「允许不受信任的快捷指令」。导入后，你仍然要自己创建一次 Message 自动化。
