安装 Pigeon，
并让验证码自动到达 Windows

先在电脑上启动 Pigeon，再用 iPhone Shortcuts 建立短信自动化。设置一次，以后网站发送验证码后，直接在 Windows 按 Ctrl + V。

网站发送验证码→iPhone 自动转发→Ctrl + V
开始前 启动 Pigeon 配置 Shortcuts IP 变化 验证结果

开始前

  • 解压完整的 Pigeon ZIP
  • iPhone 与电脑连接同一台路由器
  • Windows 当前网络设为“专用网络”
A

在 Windows 上启动 Pigeon

完成后，Pigeon 窗口会给出 Shortcuts 需要的 URL 和配对 token。

  1. 解压并运行 Pigeon.exe

    下载 ZIP 后先完整解压，再双击 Pigeon.exe。SmartScreen 出现时点击“仍要运行”。

  2. 只允许专用网络

    防火墙弹窗中勾选“专用网络”，不要勾选“公用网络”，然后点击“允许”。

  3. 复制 URL 和配对 token

    保持 Pigeon 运行。稍后需要复制窗口中的“快捷指令 URL”和“配对 token”。

IP

电脑 IP 改变后怎么办？
重新复制 Pigeon 窗口中的“快捷指令 URL”，只替换 Shortcuts 里 URL 动作的地址。Message 自动化、POST 方法和两个 JSON 字段都不需要重建。

最后验证一次

让 iPhone 收到一条同时包含“验证码”和 4～8 位数字的短信。成功时，Pigeon 的“最近事件”会显示“OTP 已复制”。

  1. 收到验证码短信
  2. Pigeon 显示“OTP 已复制”
  3. Windows 按 Ctrl + V
